# 数据对账工具

根据业务指定的计算规则，将数据中心的待结算订单加工为重算账单，与结算中心的月度账单核对，定位差异并生成可复现的对照案例。

## 业务流程

1. 获取指定结算范围内的数据中心订单和结算中心月度账单。
2. 按业务确认的计算规则加工订单，生成重算账单。
3. 按约定的匹配字段对齐两侧账单，识别缺失、重复和金额不一致等差异。
4. 展示相关订单、计算过程与原始账单，提供差异核查依据。
5. 保存必要的数据快照、计算规则和执行信息，生成可重新运行的对照案例。

## 开始使用

安装 Node.js 22 或更高版本及 Spex CLI：

```bash
npm install -g @sublang/spex@6.0.0
spex lint
```

让 AI 先读取 `AGENTS.md`、`specs/map.md` 和 `specs/meta.md`，再开展规约设计。
修改规约后运行 `spex lint` 检查结构、编号和引用。

## 规约目录

| 路径 | 用途 |
| --- | --- |
| `specs/decisions/` | 设计取舍、理由与约束 |
| `specs/intents/` | 本轮交付、任务与验证计划 |
| `specs/packages/` | 按概念组织的行为与验证规约 |
| `specs/map.md` | 决策与规约包索引 |
| `specs/meta.md` | 规约编写规则 |

## 待业务确认

- 数据获取方式及两侧数据的提取时点。
- 结算月份的归属依据和参与结算的订单范围。
- 账单匹配字段、汇总粒度及重复数据处理方式。
- 退款、调整项、金额精度、舍入方式及差异判定规则。
- 差异案例需要保留的数据范围与重放条件。

## 本地数据

本地订单、账单及对账产物可存放在 `data/`、`artifacts/` 或 `exports/`，这些目录已加入 Git 忽略规则。
